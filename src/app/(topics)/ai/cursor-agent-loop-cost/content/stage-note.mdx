**어디서를 폴더나 파일·함수로 옮겨 보세요.** 시작 칸이 내려가는데 비용은 오히려
**올라갑니다.** 도달한 칸이 그대로 `작업 폴더 밖`이기 때문입니다 — 좁게 시작한 만큼
좁은 칸의 탐색값을 더 내고, 못 찾은 뒤에는 어차피 위로 올라갔습니다.

**이번에는 언제 그만둘지만 켜 보세요.** 어디서를 다시 `안 적음`으로 돌려 두어도 호출이
5번으로 떨어집니다. 올라가는 일 자체가 없어지기 때문입니다.

**둘을 같이 켜면** 호출이 1번이 됩니다. 범위가 시작할 칸을 정하고 중단 조건이 끝낼 칸을
정하니, 탐색이 한 칸에서 끝납니다. <strong>이 둘은 짝일 때만 값을 합니다.</strong>

마지막으로 <strong>찾는 것이 실제로 있다</strong>를 켜 보세요. `어디서`를 파일·함수까지
좁혀 두었다면 **있는데 못 찾음**이 뜹니다. 가장 싼 조합이 가장 좋은 조합은 아닙니다.

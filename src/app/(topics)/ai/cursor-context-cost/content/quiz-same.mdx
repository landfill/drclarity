`Cache Read` 는 문맥 위에 한 번 더 얹히는 별도의 문맥이 아닙니다. **이번 호출에 들어간
입력 가운데 다시 읽지 않고 재사용한 몫**을 가리키는 사용량 항목입니다.

Anthropic 문서가 이 관계를 그대로 씁니다 — <strong>입력 전체 = 캐시 읽기 + 캐시 쓰기 +
새 입력</strong>. 셋은 캐시 경계를 기준으로 나뉜 조각이라 서로 겹치지 않습니다. 경계보다
앞이면서 이미 캐시에 있으면 읽기, 앞이면서 지금 올리면 쓰기, 뒤에 있으면 새 입력입니다.

그러니 82.4K 를 재사용하고 0.1K 를 새로 처리했다면 모델이 본 것은 82.5K 입니다.

방을 옮기라는 규칙이면 무엇이든 되는 것은 아닙니다. "1번과 2번 손님은 1번 방으로,
3번과 4번은 2번 방으로, 이렇게 둘씩 짝지어 옮기세요"라고 하면 어떻게 될까요.
방은 절반만 쓰이지만, 한 방에 두 명씩 들어갑니다. 한 명은 나가야 합니다.

필요한 조건은 **서로 다른 손님이 서로 다른 방으로 간다**는 것입니다. 수학에서는
이것을 <Highlight>단사(injective)</Highlight>라고 부릅니다. n → n + 1 도, n → 2n 도
단사입니다. 그래서 두 규칙 모두 아무도 밀어내지 않습니다.

여기에 하나가 더 필요합니다. 옮겨 간 자리가 **모든 방을 덮지는 않아야** 빈 방이
생깁니다. n → n + 1 은 1번을 덮지 않고, n → 2n 은 홀수를 통째로 덮지 않습니다.
유한한 호텔에서는 이 두 가지가 동시에 성립할 수 없습니다 — 단사이면 반드시
전체를 덮습니다. 무한에서만 갈라지는 지점이 여기입니다.
